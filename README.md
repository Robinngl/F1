# 🏎️ Analyse F1 2025 - Dashboard de Robin

Ce projet utilise la bibliothèque **FastF1** pour extraire et visualiser les données de la saison 2025.

## 📊 Fonctionnalités
* Génération du classement mondial cumulé (Courses + Sprints).
* Visualisation de l'évolution des points par pilote.
* Couleurs officielles des écuries intégrées.

## 🚀 Comment ça marche ?
Le script principal `2025.py` récupère les données via l'API Ergast/FastF1 et génère un graphique haute résolution.
